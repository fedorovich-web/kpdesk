# KPDesk

**Русский** | [English](README.en.md)

Сервис для подготовки коммерческих предложений по заявкам покупателей. Помогает
разобрать требования клиента, подобрать товары из прайса компании, рассчитать
стоимость и собрать PDF после проверки менеджером.

[Сайт проекта](https://kpdesk.ru) · [Демо](https://kpdesk.ru/demo) · [Рабочий кабинет](https://kpdesk.ru/app)

## Какую задачу решает

Менеджеру поставщика приходится переносить позиции из письма клиента в таблицу,
искать товары в прайсе, сравнивать характеристики и заново оформлять предложение.
Если заявка меняется, состав и суммы нужно проверять повторно.

KPDesk объединяет эти шаги в одном кабинете. Исходные требования остаются рядом
с найденными товарами, цены берутся из прайса компании, а окончательный состав
и текст предложения проверяет менеджер.

## Возможности

| Задача | Что можно сделать |
| --- | --- |
| Загрузить прайс | Импортировать CSV или XLSX с артикулами, ценами, единицами продажи и характеристиками. |
| Разобрать заявку | Получить ИИ-черновик позиций и требований или заполнить их вручную. Проверить количества, единицы и исходные цитаты. |
| Подобрать товары | Сравнить кандидатов из своего каталога с требованиями клиента и выбрать подходящие позиции. |
| Рассчитать стоимость | Учесть количество, совместимые единицы измерения, базу цены и шаг продажи. |
| Добавить реквизиты | Найти отправителя и заказчика по ИНН через DaData, проверить данные и включить их в документ. |
| Подготовить КП | Проверить текст и условия, сохранить версию и скачать PDF с таблицей товаров, суммами и реквизитами. |
| Вернуться к работе | Открыть сохранённое предложение, посмотреть его состав и историю версий. |
| Работать командой | Разделять данные организаций и учитывать права участников. |

Неизвестные и противоречивые значения требуют уточнения. ИИ не назначает цены
и не утверждает предложение за менеджера. Документ может занимать несколько
страниц — количество страниц зависит от состава и текста КП.

## Попробовать

1. Откройте [демо](https://kpdesk.ru/demo), чтобы посмотреть сценарий на учебных данных.
2. В рабочем кабинете загрузите прайс компании и добавьте заявку покупателя.
3. Проверьте требования и подходящие товары, укажите реквизиты и условия.
4. Сохраните предложение и скачайте PDF.

Демо работает без регистрации и не обращается к внешнему ИИ.

## Инженерные решения

- **Проверяемые данные.** Структура ответа ИИ и соответствие исходной заявке проверяются до использования в предложении.
- **Отдельный расчёт стоимости.** Цены берутся из каталога, денежные значения рассчитываются через Decimal.
- **Сохранение версий.** Состав, условия и реквизиты связаны с конкретной версией документа; изменение профиля компании не переписывает старые КП.
- **Контроль доступа на сервере.** Данные и действия привязаны к организации и правам участника.
- **Управляемая генерация текста.** Обращения к ИИ учитываются отдельно; ошибки и отмена не выдаются за успешный ответ.

## Стек и структура

| Часть проекта | Технологии | Исходный код |
| --- | --- | --- |
| Сайт и рабочий кабинет | TypeScript, React, Vite | [frontend](frontend) |
| API и бизнес-логика | Python, FastAPI, Pydantic | [backend/src/kpdesk](backend/src/kpdesk) |
| Данные | PostgreSQL, SQLAlchemy, Alembic | [backend/migrations](backend/migrations) |
| Подбор товаров и расчёты | Правила совместимости, лексическое ранжирование, Decimal | [universal](backend/src/kpdesk/universal) |
| PDF | ReportLab | [quotes](backend/src/kpdesk/quotes) |

Приложение контейнеризовано с Docker. Версии зависимостей зафиксированы
в `frontend/package-lock.json` и `backend/uv.lock`.

## Проверка качества

pytest и Vitest проверяют серверную логику и поведение интерфейса. Отдельные
проверки охватывают расчёты, сохранение версий, права доступа, импорт прайсов,
обработку ответов ИИ и содержание PDF. В проекте используются проверка типов,
линтеры, production-сборка и браузерные сценарии.
